# Retraction exposure in medical RAG

How often does a medical RAG system pull in retracted papers, or papers that cite them, and does filtering retracted papers out of the index fix it? This repo measures that on a PubMed subset using Retraction Watch and PubMed retraction labels. It's a pilot, so all numbers are preliminary.

## Background

Retracted papers keep getting cited, usually without a note. In a PubMed Central study of 7,813 retracted papers, only 722 of 13,252 post-retraction citation contexts (5.4%) acknowledged the retraction ([Hsiao & Schneider, 2021](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC9520488/)). A 2025 stem-cell study found 14 of 334 (4.2%) ([BMC Medicine](https://doaj.org/article/1e794786dc2d48d29ab835d1fe8e2d28)). Chatbots show the same gap: ChatGPT-5.0 used 72 of 117 retracted stem-cell articles in its answers, and 30 of those 72 answers included a retraction notice ([Zhang et al., 2025](https://ideas.repec.org/a/spr/scient/v130y2025i11d10.1007_s11192-025-05484-y.html)).

The LLM-side work I found is small chatbot audits ([Yao et al.](https://pmc.ncbi.nlm.nih.gov/articles/PMC12583397/), [Labenbacher et al.](https://www.jmir.org/2026/1/e88766), [Thelwall](https://arxiv.org/pdf/2604.16872)). I haven't found one that measures this at the retrieval level in a standard medical RAG pipeline.

## What I'm measuring

- Direct exposure: a retrieved paper is itself retracted.
- One-hop exposure: a retrieved paper isn't retracted but cites a retracted one. This is a risk flag, not proof the citing paper is wrong. Retraction notices are excluded from the citing side.

Hypotheses:

1. Retrievers return retracted papers, and papers citing them, at a rate different from the base rate of the corpus they search.
2. An index-time retraction filter removes direct exposure but leaves one-hop exposure, which should be several times more common.
3. Removing a retracted source changes the answer in a measurable share of exposed questions.

If retrieval turns out to be neutral, exposure just tracks base rates, and that's a result too.

## Setup

- Corpus: a uniform ~5% sample of [MedRAG's PubMed corpus](https://arxiv.org/pdf/2402.13178) (every 20th baseline file, 58 files, 1,224,889 abstracts). The full corpus is 23.9M snippets from a Feb 2024 snapshot, about 70 GB of text, so I'm piloting on the sample and may scale up later.
- Questions: MIRAGE, 7,663 questions. The query is the question text only, without the answer options.
- Retriever: BM25 through Pyserini with default parameters, k = 32.
- Retraction labels: Retraction Watch (`RetractionNature == "Retraction"`) combined with PubMed's "Retracted Publication" tag.
- Retraction notices: PubMed's notice list combined with Retraction Watch's `RetractionPubMedID`. Notices that are not themselves retracted papers are excluded from the citing side.
- Citation links: iCite API (`cited_by`). iCite only has PubMed-to-PubMed links.
- Base rates are computed on the same subset the retriever searches.
- Severity classes: the 110 Retraction Watch reasons are grouped into A (data, results, image, method or material problems), B (misconduct, ethics, authorship, peer review), C (investigations, unclear) and D (administrative, such as "withdrawn as out of date"). A paper takes the highest class among its reasons. Papers with no listed reason are class U. The grouping is mine; see `src/reason_map.py`.
- Timing: a citing paper is labelled before, same year, or after the retraction by comparing publication year (iCite) with retraction year (Retraction Watch). Only year-level dates are available.

## Reproduce so far

Needs Python 3.12 and Java (tested on 23; Pyserini targets 21).

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# Retraction Watch (shallow clone; the full history is ~4 GB)
git clone --depth 1 https://gitlab.com/crossref/retraction-watch-data data/raw/retraction-watch-data

# PubMed retraction tag and retraction notices (needs NCBI EDirect)
esearch -db pubmed -query '"Retracted Publication"[pt]' | efetch -format uid > data/raw/pubmed_retracted_pmids.txt
esearch -db pubmed -query 'hasretractionof OR "retraction notice"[pt]' | efetch -format uid > data/raw/pubmed_retraction_notice_pmids.txt

# MIRAGE
git clone --depth 1 https://github.com/Teddy-XiongGZ/MIRAGE third_party/MIRAGE

# Corpus subset: every 20th baseline file of MedRAG/pubmed (~3.5 GB)
python - <<'EOF'
from huggingface_hub import hf_hub_download
import os
os.makedirs("data/raw/pubmed_subset", exist_ok=True)
for i in range(20, 1300, 20):
    try:
        hf_hub_download("MedRAG/pubmed", f"chunk/pubmed23n{i:04d}.jsonl",
                        repo_type="dataset", local_dir="data/raw/pubmed_subset")
    except Exception as e:
        print("skip", i, type(e).__name__)
EOF
```

Then, in order:

```bash
python src/build_labels.py
python src/scan_corpus.py
python src/check_mirage_gold.py
python -m pyserini.index.lucene --collection JsonCollection \
  --input data/raw/pubmed_subset/chunk --index data/processed/bm25_subset \
  --generator DefaultLuceneDocumentGenerator --threads 4 --storeRaw
python src/check_bm25_index.py
python src/fetch_icite_citing.py
```

Build the notice lists (the union, then the exclusion list: notices that are not retracted papers):

```bash
python - <<'EOF'
import pandas as pd
df = pd.read_csv("data/raw/retraction-watch-data/retraction_watch.csv", low_memory=False)
rw = pd.to_numeric(df["RetractionPubMedID"], errors="coerce")
rw = set(rw[rw > 0].astype(int))
pm = set(int(x) for x in open("data/raw/pubmed_retraction_notice_pmids.txt") if x.strip().isdigit())
union = rw | pm
open("data/processed/notice_pmids.txt", "w").write("\n".join(map(str, sorted(union))))
retracted = set(pd.read_parquet("data/processed/retracted.parquet")["pmid"])
excl = union - retracted
open("data/processed/notice_exclude_pmids.txt", "w").write("\n".join(map(str, sorted(excl))))
print(len(union), len(excl))
EOF
python src/build_one_hop_flags.py
python src/run_bm25_retrieval.py
```

Analysis (no network except where noted):

```bash
python src/analyze_exposure.py
python src/extra_checks.py
python src/hub_inspect.py
python src/reason_classes.py
python src/filter_ablation.py
python src/severity_exposure.py      # writes data/processed/retracted_classes.parquet
python src/fetch_icite_years.py      # network: iCite API, years of the retrieved one-hop papers
python src/timing_split.py
python src/make_figures.py           # writes figures/f1..f8 and checks them against the results files
```

## Results so far

- Labels: 37,201 retracted PMIDs. Retraction Watch has 30,546, the PubMed tag has 35,274, and 28,619 are in both. 21 also have a reinstatement record in Retraction Watch and are flagged.
- Corpus subset: 1,224,889 abstracts, 1,528 of them retracted (0.12%).
- MIRAGE gold evidence: 0 of PubMedQA's 500 gold papers are retracted, and 6 of BioASQ's 3,467. That's about what chance predicts at this base rate (expected ~4.3). Only ~5% of gold papers are in the subset (23 for PubMedQA, 194 for BioASQ).
- BM25 index: 1,224,889 documents, 1.5 GB, count matches the corpus scan. All 23 PubMedQA gold papers that are in the subset come back at rank 1. That's an easy test, so it checks the index and PMID mapping, not retrieval quality on real queries.
- Notice lists: 34,200 from PubMed and 31,668 unique from Retraction Watch, 38,142 combined (27,726 in both). NLM renamed "Retraction of Publication" to "Retraction Notice" in 2026, so the query uses the new name ([NLM Technical Bulletin](https://www.nlm.nih.gov/pubs/techbull/ma26/ma26_pubmed_update_MeSH_changes.html)). 1,493 of the combined list are also retracted papers (the notice reuses the paper's PMID), so the exclusion list drops those and keeps 36,649. In the subset there are 291 notices, 57 of them also retracted, leaving 234 to exclude.
- Citation links: iCite returned 37,135 of the 37,201 retracted PMIDs, with 735,647 (retracted, citing) pairs from 597,694 unique citing papers. The median retracted paper has 7 citing papers and the max is 4,217. After dropping notices, 719,914 pairs remain, and 27,491 of them have a citing paper in the subset.
- One-hop flags: 21,696 subset snippets (1.77%) cite a retracted paper. That is 21,695 distinct PMIDs, because one PMID (35083036) has two snippets. 85.1% cite exactly one, 10.5% cite two, and 4.4% cite three or more.
- Retracted papers citing retracted papers: 402 of the 1,528 retracted abstracts in the subset (26%) cite another retracted paper, and overall it's 9,688 of 37,201 (26.0%). For non-retracted abstracts it's 1.8%. This is an observation, not a finding. Retractions cluster by topic and in networks of papers that cite each other.
- Retrieval: BM25 (k = 32) over all 7,663 MIRAGE questions returned 245,121 rows. Four very short MedMCQA questions (one rare term plus function words, like "Arestin is:") returned fewer than 32 hits, probably because the 5% subset has few documents with that term.
- Direct exposure: 3.42% of questions (262) retrieved at least one retracted abstract at top 32, and 0.46% (35) at top 5. Retracted abstracts are 0.113% of retrieved rows against a 0.125% corpus base rate, so retrieval looks neutral overall. By dataset at top 32: BioASQ 9.2%, MedMCQA 3.7%, PubMedQA 3.6%, MMLU 2.4%, MedQA 0.6%.
- One-hop exposure: 31.4% of questions (2,404) retrieved at least one abstract that cites a retracted paper at top 32, and 9.3% (714) at top 5, from 1.50% of rows against a 1.77% base rate. By dataset at top 32: BioASQ 60.0%, MedQA 40.4%, MMLU 33.2%, PubMedQA 30.0%, MedMCQA 24.1%.
- For reference, random retrieval of 32 abstracts would give about 3.9% of questions with a retracted abstract and about 44% with a one-hop abstract (arithmetic from the corpus rates).
- By rank: retracted abstracts are slightly under-represented in ranks 1 to 5 (0.091% against 0.125%). One-hop abstracts are slightly over-represented there (2.01% against 1.77%), and part of that comes from the hub paper below.
- BioASQ runs about 2.6 times the base rate in rows for both measures. That's probably a topic effect: it asks about specific research topics where retractions and their citers are dense. It needs a topic-matched baseline, so treat it as a lead.
- Direct hits land in different questions (3.42% of questions observed vs 3.54% if independent). One-hop hits clump in the same questions (31.4% vs 38.4%), except in MedQA.
- Retraction notices show up in 0.18% of questions (14), so they barely matter here.

**Hub paper.** One paper (PMID 25032021, a case-study-style review on breathlessness in lung metastases) is retrieved for 521 questions (MedQA 402, MMLU 95, MedMCQA 23, PubMedQA 1), 283 of them in the top 5. The next most-retrieved one-hop papers appear for 104, 55 and 24 questions. The hub paper cites one retracted paper: a 2008 Cochrane review (PMID 18425927), withdrawn in November 2013 as out of date. Its notice is a separate PubMed record (PMID 24272974), so the review carries a Retraction Watch entry but not the PubMed retraction tag. Removing the 23 papers that appear in 5 or more questions, without back-filling, lowers one-hop exposure from 31.4% to 23.1% at top 32 and from 9.3% to 5.0% at top 5. For MedQA at top 5 it falls from 19.5% to 0.7%.

**Filter ablation.** Fetching the top 100 and rebuilding lists of up to 32:

| List | Top 5 retracted | Top 5 one-hop | Top 32 retracted | Top 32 one-hop |
|---|---|---|---|---|
| No filter | 35 (0.46%) | 714 (9.32%) | 262 (3.42%) | 2,404 (31.37%) |
| Drop retracted papers | 0 | 714 | 0 | 2,404 |
| Drop retracted and papers citing them | 0 | 0 | 0 | 0 |

Dropping retracted papers removes all direct exposure and leaves one-hop unchanged. That is partly built in, since a filter on retracted status can't touch papers that aren't retracted. The strict filter changes the top 5 for 9.64% of questions (BioASQ 21.4%, MedQA 19.5%, MMLU 9.0%, PubMedQA 6.8%, MedMCQA 5.4%), against 0.46% for the plain filter.

**Severity.** Of the 37,201 retracted PMIDs, 61.4% are class A, 15.6% B, 0.2% C, 4.8% D, and 17.9% U (all PubMed-tag-only, with no listed reason). Of the 189 distinct retracted papers retrieved, 55.0% are class A and 12.7% are D. Direct exposure from class A papers is 0.21% of questions at top 5 (16) and 1.88% at top 32 (144). One-hop exposure through a class A paper is 3.55% at top 5 (272) and 16.91% at top 32 (1,296), so class A accounts for 38% of one-hop questions at top 5 and 54% at top 32. The hub paper's strongest cited class is D, which is why the top-5 headline falls so much under the strict view (MedQA 19.5% to 0.7%). 16.2% of corpus one-hop papers (3,524 of 21,695) cite only class D or U retracted papers. Papers with no reason are not counted as class A, so the strict figures are lower bounds.

**Timing.** For the 2,296 retrieved one-hop papers, iCite gave a publication year for all of them (1980 to 2024). Of 2,876 (retracted, citing) pairs, 2,537 involve a dated retraction: 1,672 (66%) were cited before the retraction year, 270 (11%) in the same year, 595 (23%) after. 339 pairs have no retraction date (tag-only papers). At the paper level, 2,082 have at least one dated pair: 1,305 cite only before, 553 have at least one citation after, and 224 are same-year or mixed. At the question level, 10.0% of questions at top 32 (767) and 1.80% at top 5 (138) have a one-hop paper with a citation made after the retraction year. Without the 23 repeat papers the top-5 figure is 1.42% (109), so it does not depend on the hub. For class A cited papers only, it is 4.76% at top 32 (365) and 0.86% at top 5 (66). The hub paper's one citation is same-year (2013 and 2013, class D).

## Limitations

- The subset is ~5% of the corpus, so each question has less competition than in the full corpus. Hub papers may matter less in a larger corpus.
- BM25 only, with no dense retriever comparison yet.
- Counts are small in places (8 MedQA questions and 18 PubMedQA questions have a retracted hit), and there are no confidence intervals yet.
- Retraction dates and reasons exist only for papers in Retraction Watch (30,546 of 37,201, 82%). Papers that only carry the PubMed tag have neither, so they drop out of the timing split and are class U. Strict and timing figures are lower bounds for that reason.
- The severity grouping is my own. For example, "Cites Retracted Work" and "Error in Text" sit in class A.
- Timing is year-level. A citation in the retraction year can't be placed before or after, and Retraction Watch's date is the notice date, which can lag the problem coming to light. A citation after the retraction year doesn't show the authors knew.
- Timing was fetched only for the retrieved one-hop papers (2,296), not the whole corpus.
- Labels are current but the corpus snapshot is from Feb 2024, so some papers were retracted after the index was built.
- Snippets are abstracts, not full text. 62 PMIDs have two snippet rows, and counts are per snippet unless stated as PMIDs.
- One-hop is a lower bound, since iCite only has PubMed-to-PubMed links. It's also a risk flag: a paper that cites a retracted one to criticize it still counts.
- The filter ablation result for one-hop is partly mechanical. What it shows is how large and how concentrated the remaining one-hop exposure is.
- The subset holds ~5% of MIRAGE's gold evidence, so RAG answers can't be scored against the benchmark's answer labels. The answer-change test compares answers with and without a retracted source instead.
- Only known retractions are flagged.
